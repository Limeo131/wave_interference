# Holton–Mass Interference

Code for a study of stationary–free-wave interference and SSW-like transitions
in the Holton–Mass (1976) beta-plane model.

This repository contains the **model and analysis code**. Model output data,
figures, and the manuscript are not included while the paper is under review;
they will be released once the paper is published.

## Layout

```
models/      Pure computation (no plotting).
             - hm76.py       Holton–Mass model: integrator, eigensolver, diagnostics.
             - two_level.py  Two-level quasi-linear model.
plot/        Plotting routines (import from models/).
scripts/     Parameter sweeps, figure generation, and diagnostic scripts.
fortran/     Fortran sources for the ERA5 / QGPV preprocessing.
```

## Requirements

Python 3.9+, with `numpy`, `scipy`, `matplotlib` (and `netCDF4` / `xarray` for
the data-handling scripts). Scripts are designed to be run from the repository
root, e.g.:

```bash
python scripts/run_sweep_fig01.py
```

## Notes

- `models/` holds all computation and is imported everywhere; plotting lives in
  `plot/`. Scripts save intermediate model output as `.npz` so that plotting
  never requires re-running the model.
- Generated data (`.npz`, `.nc`) and figures are git-ignored and regenerated by
  the scripts.
