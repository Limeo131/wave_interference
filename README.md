# Wave Interference in the Holton–Mass Model

Model and analysis code for a study of stationary–free-wave interference and
sudden-stratospheric-warming (SSW)-like transitions in the Holton–Mass (1976)
beta-plane channel model.

The central question is why different forcing spin-up times can produce
different SSW-like outcomes at the same final lower-boundary forcing amplitude.
The code implements the Holton–Mass model, a free-mode (eigenmode) analysis, a
stationary/free-wave interference decomposition, and wave-propagation
diagnostics, and uses them to sweep the forcing-amplitude / spin-up-time
parameter space.

## Status

This repository contains the **model and analysis code only**. Generated model
output, figures, and the manuscript are withheld while the paper is in
preparation; they will be released with publication.

## Repository layout

```
models/      Pure computation, no plotting. Imported everywhere.
             - hm76.py       Holton–Mass model: integrator (run_hm76),
                             eigensolver (solve_hm76_eigenmodes), modal
                             projection, and wave/mean-flow diagnostics
                             (compute_m2, compute_epflux_zt, compute_min_m2, ...).
             - two_level.py  Two-level quasi-linear model (supporting material).
plot/        Plotting routines; each imports from models/.
             - plot_hm_model.py, plot_two_level.py, plot_fp_timeseries.py
scripts/     Parameter sweeps, figure generation, and diagnostic scripts
             (run from the repository root).
fortran/     Fortran sources used to preprocess raw reanalysis fields into
             quasi-geostrophic PV / winds (upstream of the observational
             analysis, which is not part of this release).
```

Workflow convention: `models/` holds all computation and is imported
everywhere; `plot/` does plotting only. Scripts save intermediate model output
as `.npz`, so replotting never requires re-running the model.

## Requirements

- Python 3.9+
- `numpy`, `scipy`, `matplotlib`
- `netCDF4` (and optionally `xarray`) for scripts that read/write NetCDF

## Quick start

Run the core Holton–Mass model directly:

```python
from models.hm76 import run_hm76, compute_m2, compute_min_m2

# hb in metres; tau (forcing spin-up time) in SECONDS.
# A representative transitioning ("burst") case: hb = 30 m, tau = 10 days.
out = run_hm76(
    hb=30.0,
    tau=10.0 * 86400.0,   # 10 days -> seconds
    s=2.0,                # zonal wavenumber 2
    n_days=300,
    alpha_on=False,
    wave_mean_feedback=True,
)

# Stationary-wave refractive index m^2(z, t) and the propagation-barrier metric.
m2 = compute_m2(out, c=0.0, s=2.0)
M_t = compute_min_m2(m2, out["z"], z1_km=25.0, z2_km=40.0)
```

Set `wave_mean_feedback=False` for the frozen-background (no wave–mean-flow
interaction) control used in the free-mode analysis.

## Scripts

Scripts are grouped by name prefix:

- `run_sweep_*` / `run_*` — run model integrations or parameter sweeps and save
  results to `.npz` (these are the compute-heavy steps).
- `make_manuscript_fig0N.py`, `make_figures.py`, `plot_*` — build figures from
  previously saved `.npz` output.
- `step1_*`, `step2_*` — staged mechanism analysis (propagation-barrier
  diagnosis; free-mode eigenproblem and projection).
- `audit_*`, `*_second_order_*`, `test_*`, `_verify_*` — verification,
  reproducibility, and sensitivity checks.

Because generated `.npz`/`.nc` data are not tracked (see below), the plotting
scripts depend on the corresponding `run_*` script having been executed first.
For example, generate the sweep, then plot it:

```bash
python scripts/run_sweep_fig04.py    # produces the .npz the next step reads
python scripts/plot_fig04.py         # reads that .npz and draws the figure
```

Run all scripts from the repository root so that `from models... import ...`
resolves.

## Reproducibility and data

- Generated data (`*.npz`, `*.nc`) and figures are `.gitignore`d and are
  intended to be regenerated by the scripts, not stored in version control.
- The observational (reanalysis) analysis and its inputs are not included in
  this release.
